# 📊 Análise de Dados em Python

Repositório de estudos em Análise de Dados, construído em paralelo ao curso
de Desenvolvimento de Software Multiplataforma (FATEC) e à minha transição
de carreira da área jurídico-societária para Dados, Analytics e BI.

## Sobre

Aqui eu aplico numpy, pandas, estatística, visualização e SQL sobre datasets
reais — sempre documentando as decisões (por que limpar um dado de um jeito
e não de outro, por que escolher um gráfico e não outro), não só o código.

**Pré-requisito:** módulos 1–6 do repositório
[`logica-programacao-python`](https://github.com/maxgodoydev/logica-programacao-python)
concluídos antes de avançar em pandas/numpy — sem fundamentos sólidos de
Python, biblioteca vira "código copiado sem entender".

O roadmap completo, módulo por módulo, está em [`ROADMAP.md`](ROADMAP.md).

## Sobre o próximo passo (Engenharia de Dados)

Este repositório cobre a trilha de **Análise** de dados. Engenharia de
Dados usa boa parte da base de Python e SQL construída aqui, mas exige um
conjunto próprio de habilidades (modelagem de banco, ETL/orquestração,
processamento distribuído, infraestrutura) que ficará documentado em um
terceiro repositório quando eu chegar nessa etapa.
