# 🧠 Lógica de Programação & Dados em Python

Repositório de fixação de lógica de programação e análise de dados, construído como parte da minha trilha de estudos em Desenvolvimento de Software Multiplataforma (FATEC) e da minha transição de carreira para Dados, Analytics e BI.

## Sobre

Cada desafio aqui resolve um problema prático e específico (estruturas de dados, condicionais, loops, manipulação com Pandas, SQL e automação) com o objetivo de fixar fundamentos essenciais. A ideia não é só "fazer rodar sem erro", mas entender a eficiência do código, aplicar boas práticas e evoluir progressivamente até a construção de pipelines de dados completos.

O progresso detalhado e a ementa dos módulos estão documentados em [`ROADMAP.md`](ROADMAP.md).
