# 🧠 Lógica de Programação em Python

Repositório de fixação de lógica de programação, construído como parte da
minha trilha de estudos em Desenvolvimento de Software Multiplataforma
(FATEC) e da minha transição de carreira para Dados, Analytics e BI.

## Sobre

Cada desafio aqui resolve um problema pequeno e específico (listas de
dicionários, condicionais, loops, funções, etc.) com o objetivo de fixar
fundamentos antes de avançar para bibliotecas como pandas e numpy. A ideia
não é só "fazer rodar sem erro", mas entender por que cada solução funciona
e como ela poderia ser melhorada.

O progresso completo, módulo por módulo, está documentado em [`ROADMAP.md`](ROADMAP.md).
