# Desafio 01 — Produtos Entregues

## Enunciado

Uma loja registrou os seguintes produtos:

| Produto  | Valor   | Status   |
|----------|---------|----------|
| Teclado  | R$ 250  | Entregue |
| Mouse    | R$ 120  | Pendente |
| Monitor  | R$ 900  | Entregue |
| Headset  | R$ 180  | Entregue |

**Objetivo:** criar um programa que:

1. Armazene os produtos e suas informações.
2. Verifique quais produtos foram entregues.
3. Some apenas o valor dos produtos entregues.
4. Mostre o resultado final no terminal.

## Observação de revisão

O requisito 2 pede para "verificar quais produtos foram entregues", mas a
solução atual só imprime o total — nenhuma listagem individual mostra o que
foi ou não entregue. Funciona, mas não evidencia o requisito 2 de forma
explícita no output. Vale considerar adicionar um print por item.

## Como executar

```bash
python3 desafio_01.py
```
