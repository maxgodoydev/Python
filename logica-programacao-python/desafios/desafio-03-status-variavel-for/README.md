# Desafio 03 — Variável criada dentro de um laço `for`

## Enunciado

Praticar o uso de uma variável criada dentro de um laço `for`, usando os
mesmos funcionários do Desafio 02.

**Objetivo:** criar um programa que:

1. Percorra todos os funcionários.
2. Verifique se cada funcionário está ativo ou inativo.
3. Crie uma variável para representar o status.
4. Mostre o nome e o status de cada funcionário.
5. Apresente a quantidade total de ativos e inativos.

## Observação de revisão

O arquivo original tinha o comentário de cabeçalho `#Desafio_2` (sobra de
copy-paste do arquivo anterior) — corrigido para `#Desafio_3` nesta versão.
Fora isso, esta é a melhor implementação dos três primeiros desafios: loop
único, sem repetição desnecessária de iteração sobre a lista.
